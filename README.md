# 24 Cat Personality Quiz 🐱

> 你的内在猫格原型测试 — An interactive personality quiz mapping human traits to 24 cat archetypes.

## Concept

Based on **Big Five (OCEAN)** personality model and **Attachment Theory**, this quiz maps your behavioral patterns to feline survival strategies. Answer 15 questions and discover which of the 24 "cat personalities" you embody — plotted on two dimensions: **Independence** and **Emotional Stability**.

## Features

- 🎨 Clean UI with Tailwind CSS + custom animations
- 🧠 Psychology-backed scoring algorithm (OCEAN + Attachment Theory)
- 📊 24 unique cat archetype results with detailed descriptions
- 📱 Fully responsive design
- 🇨🇳 Chinese-language interface

## Tech Stack

- **Frontend**: Vanilla JavaScript + HTML5
- **Styling**: Tailwind CSS (CDN)
- **Font**: Noto Sans SC (Google Fonts)
- **Architecture**: Single-page application, no build tools needed

## Try It

Open `index.html` in any browser — no installation required.

## Screens

- Start screen → 15-question quiz → Personality result with cat archetype description
